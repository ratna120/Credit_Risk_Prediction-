Credit Risk Prediction Using Machine Learning

Overview

This project predicts whether a loan applicant is likely to be a high-risk or low-risk borrower using Machine Learning techniques.
The objective is to help financial institutions reduce loan defaults and improve credit approval decisions.

Features

* Data Preprocessing
* Feature Engineering
* Exploratory Data Analysis
* Logistic Regression Baseline Model
* Random Forest Classifier
* Hyperparameter Tuning using GridSearchCV
* Feature Importance Analysis
* Model Saving using Joblib

Dataset Features

* Age
* Gender
* Education
* Employment Status
* Annual Income
* Loan Amount
* Credit Score
* Interest Rate
* Number of Late Payments
* Debt-to-Income Ratio
* Mortgage Status
* Loan Purpose

Engineered Features:

* loan_income_ratio
* credit_score_group

Model Performance

* Accuracy: 84%
* Precision: 71%
* Recall: 76%
* F1 Score: 73%
